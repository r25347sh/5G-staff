# ルーレットルール（ヨーロピアン・文化祭用）

> 本展示は **ヨーロピアン・ルーレット（0 のみ・37ポケット）** です。  
> チップは **物理のおもちゃチップ** を使用。画面のルーレットは **出目の確認用** です。

---

## 🎰 概要

| 項目 | 内容 |
| :--- | :--- |
| ホイール | 0〜36（**00 なし**） |
| 0 の色 | **緑** |
| 赤 | 1,3,5,7,9,12,14,16,18,19,21,23,25,27,30,32,34,36 |
| 黒 | 上記以外の 1〜36 |
| 勝敗 | ボール（またはアプリ）の出目に、置いたチップが当たれば配当 |

---

## 🔄 進行の流れ（卓上）

1. **ベット** … お客様がレイアウト上にチップを置く  
2. **ストップ** … 「これ以上置けません」と声かけ（ノーモアベット）  
3. **スピン** … ホイール／アプリで出目を出す  
4. **結果** … 数字・色を全員に見えるよう示す  
5. **清算** … 当たった賭けに配当、外れは回収  

---

## 💰 配当の読み方

- 表の「配当」は **利益の倍率**（元チップは戻る）  
  - 例: 10 をストレートで当てる → **10 が戻り、さらに 10×35＝350** → 手元 360  
- 文化祭では運営が簡略化してもよいが、**迷ったらこの表**を使う  

---

## 🎯 主な賭け方と配当（ヨーロピアン）

### インサイド・ベット（数字まわり）

| 賭け方 | 英語 | カバーする数字 | 配当（利益） |
| :--- | :--- | :--- | :---: |
| **ストレートアップ** | Straight up | **1つ**の数字（0含む） | **35 : 1** |
| **スプリット** | Split | 隣り合う **2** 数字 | **17 : 1** |
| **ストリート** | Street | 横一列 **3** 数字 | **11 : 1** |
| **コーナー** | Corner | 角で接する **4** 数字 | **8 : 1** |
| **ライン** | Line / Double street | 2列で **6** 数字 | **5 : 1** |

### アウトサイド・ベット（大きく賭ける）

| 賭け方 | 内容 | 配当（利益） |
| :--- | :--- | :---: |
| **赤 / 黒** | 色 | **1 : 1** |
| **奇数 / 偶数** | Odd / Even（**0は外れ**） | **1 : 1** |
| **ロー / ハイ** | 1–18 / 19–36（**0は外れ**） | **1 : 1** |
| **ダズン** | 1–12 / 13–24 / 25–36 | **2 : 1** |
| **カラム** | 縦列12個（レイアウトの列） | **2 : 1** |

---

## ⚠️ 0 が出たとき

| 賭けの種類 | 結果 |
| :--- | :--- |
| ストレートの **0** | **当たり**（35倍） |
| 赤・黒・奇偶・ハイロー | **外れ**（チップ没収） |
| 0 を含まないインサイド | **外れ** |

※ アメリカン（00あり）は使いません。

---

## 🗣️ お客様への短い説明例

> 「数字や色にチップを置いてください。回して止まった場所に当たっていれば、表の倍率でもらえます。  
> 赤黒は2倍（元が戻って同額の利益）、ひとつの数字は35倍の利益です。」

---

## ⏱️ 文化祭・スタッフ向け

1. 初心者には **赤黒・奇偶** から勧める  
2. 清算は **出目を指差してから** 行う  
3. もめそうならそのラウンド無効・チップ返却で次へ  
4. 画面アプリは補助。物理ホイールがある場合はそちらを優先してよい  
5. 実金禁止。おもちゃチップのみ
