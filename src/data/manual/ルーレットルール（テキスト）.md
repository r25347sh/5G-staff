# ルーレット（文化祭）

ヨーロピアン（**0 のみ**・00 なし）。チップは物理。画面アプリがある場合は**出目の確認用**。

## 進行（1ラウンド）

1. お客様がレイアウトにチップを置く
2. 「これ以上置けません」と声をかける
3. スピン（物理ホイールまたはアプリ）
4. 出目の数字と色を指差して宣言する
5. 当たりに配当、外れは回収

目安: **1ラウンド 1〜2分**。待ちが多いときは赤黒・奇偶だけに誘導する。

## ホイール

| 項目 | 内容 |
| :--- | :--- |
| 数字 | 0〜36（37ポケット） |
| 0 | **緑** |
| 赤 | 1, 3, 5, 7, 9, 12, 14, 16, 18, 19, 21, 23, 25, 27, 30, 32, 34, 36 |
| 黒 | 上記以外の 1〜36 |

## 配当（利益の倍率）

当たったとき、**賭けたチップは戻り、さらに下の倍率分が利益**。

### よく使う（アウトサイド）

| 賭け | 内容 | 利益 |
| :--- | :--- | :---: |
| 赤 / 黒 | 色 | **1倍** |
| 奇数 / 偶数 | 0 は外れ | **1倍** |
| ロー / ハイ | 1–18 / 19–36（0 は外れ） | **1倍** |
| ダズン | 1–12 / 13–24 / 25–36 | **2倍** |
| カラム | レイアウトの縦列 12 個 | **2倍** |

### 数字まわり（インサイド）

| 賭け | カバー | 利益 |
| :--- | :--- | :---: |
| ストレート | 数字 1 つ（0 可） | **35倍** |
| スプリット | 隣り合う 2 つ | **17倍** |
| ストリート | 横一列 3 つ | **11倍** |
| コーナー | 角の 4 つ | **8倍** |
| ライン | 2 列 6 つ | **5倍** |

例: 10 をストレートで的中 → 10 が戻り、利益 350 → 手元 **360**。

## 0 が出たとき

| 賭け | 結果 |
| :--- | :--- |
| ストレートの 0 | 当たり（利益 35倍） |
| 赤・黒・奇偶・ローハイ | **外れ** |
| 0 を含まない数字の賭け | **外れ** |

## 声かけ例

数字や色にチップを置いてください。止まった場所に当たっていれば表の倍率です。赤黒は元が戻って同じ額の利益、一つの数字は利益 35 倍です。

## スタッフ

- 初心者は **赤黒・奇偶** から
- 清算の前に出目を指差す
- もめそうならそのラウンド無効・チップ返却で次へ
- 実金禁止
