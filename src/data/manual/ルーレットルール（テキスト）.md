# ルーレットの基本ルール

## 🎰 概要
* **使用するもの**: ルーレットホイール（0〜36の数字。アメリカンなら00も）、ボール、チップ
* **参加人数**: ディーラー1人と、プレイヤー複数人
* **勝敗の決め方**: ボールが止まったポケットの数字・色・性質に、プレイヤーが賭けたチップが一致すれば配当を得ます。

---

## 🔄 ゲームの流れ
1. **ベット（賭け）**: プレイヤーはテーブル上の数字・色・組み合わせにチップを置きます。
2. **スピン**: ディーラーがホイールを回し、ボールを逆方向に投げ入れます。
3. **ノーモアベット**: ボールが落ちる直前に「これ以上の賭けは禁止」と宣言されます。
4. **結果確定**: ボールが止まったポケットの数字が結果となります。
5. **清算**: 当たった賭けに配当を支払い、外れたチップは回収します。

---

## 🎯 主な賭け方と配当

| 賭け方 | 内容 | 配当（概算） |
| :--- | :--- | :---: |
| **ストレートアップ** | 1つの数字に直接賭ける | **35倍** |
| **スプリット** | 隣接する2つの数字に賭ける | **17倍** |
| **ストリート** | 横一列の3つの数字 | **11倍** |
| **コーナー** | 4つの数字が交わる角 | **8倍** |
| **ライン** | 2つのストリート（6数字） | **5倍** |
| **ダズン** | 1-12 / 13-24 / 25-36 のいずれか | **2倍** |
| **カラム** | 縦の列（12数字） | **2倍** |
| **赤・黒** | 色に賭ける | **1倍** |
| **奇数・偶数** | 奇数または偶数 | **1倍** |
| **ハイ・ロー** | 1-18 または 19-36 | **1倍** |

※ 0（およびアメリカンの00）は通常、赤黒・奇偶・ハイローなどの「イーブンマネー」賭けでは負け扱いになります。

---

## ⚠️ スタッフが注意すること
* ベットが確定した後はチップを動かさないよう案内する。
* 0が出たときの清算を正確に行う（特に赤黒など）。
* チップの色と金額の対応を事前に確認し、混同を防ぐ。
* 初心者には「赤黒」「奇数偶数」などのシンプルな賭けから勧めると良い。

---

## 📌 補足（イベント用簡易版）
本イベントでは実金ではなくチップやポイントを使用します。配当倍率は上記を基本としつつ、運営の判断で調整する場合があります。ルールに迷ったときは総務・管理者に確認してください。
