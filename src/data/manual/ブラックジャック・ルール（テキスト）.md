# ブラックジャック（文化祭）

21 に近い方が勝ち。**22 以上はバスト（即負け）**。文化祭では回転のためルールを簡略化する。

## この卓の約束（簡易）

| 項目 | 内容 |
| :--- | :--- |
| 人数 | ディーラー 1 ＋ お客様 **最大 3** |
| デッキ | 52 枚（ジョーカーなし）。複数デッキでも可 |
| 使わない | **スプリットなし** / **ダブルダウンなし** / **サレンダーなし** |
| お客様の操作 | **ヒット** か **スタンド** のみ |
| 1組の目安 | **2〜4 ハンド** で交代を促す |

## カードの点数

| カード | 点数 |
| :--- | :--- |
| 2〜10 | 書かれた数字 |
| J・Q・K | **10** |
| A | **1 または 11**（都合のよい方） |

## 進行（1ハンド）

1. お客様がベットを置く（推奨最低 **10**）
2. お客様に 2 枚（表）、ディーラーに 2 枚（1 枚表・1 枚裏）
3. お客様から順にヒット / スタンド
4. お客様が全員終わったらディーラーの裏を開ける
5. ディーラーは次の規則で打つ
6. 点数を比べて清算

## ディーラーの打ち方（固定）

- 合計 **16 以下** → 必ずヒット
- 合計 **17 以上** → 必ずスタンド（ソフト 17 もスタンド）

## ブラックジャック（最初の 2 枚）

最初の 2 枚が **A ＋ 10 点カード** のとき **ブラックジャック**。

| 結果 | 配当 |
| :--- | :--- |
| お客様だけ BJ | 元が戻り、利益はベットと同額（例: 10 賭け → 手元 20） |
| 双方 BJ | 引き分け（ベット返却） |
| ディーラーだけ BJ | お客様の負け（ベット没収） |

通常勝ち（BJ 以外）も **元が戻り、利益はベットと同額**。

## 勝敗のまとめ

| 結果 | 扱い |
| :--- | :--- |
| お客様がバスト | その時点で負け（ディーラーを見ない） |
| ディーラーがバスト | 残っているお客様の勝ち |
| どちらもバストしていない | 21 に近い方が勝ち。同じ点は引き分け |

## 声かけ例

21 に近づけます。カードを追加するか、今の枚数で止めるかです。超えなければディーラーと数字を比べます。

## スタッフ

- 同時に見る人数は最大 3。4 人目は次のラウンド
- 考え込みそうなら「止める（スタンド）でも大丈夫です」と促す
- 実金禁止。チップのみ
- 配りミスが明らかなときだけ配り直し
