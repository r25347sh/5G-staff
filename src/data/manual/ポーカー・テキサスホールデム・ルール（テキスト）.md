# ポーカー（通常ホールデム・参考）

本展示の本番ルールは **「ポーカー（文化祭・簡易版）」** を使う。  
このページは参考用。卓では使わない。

## 通常ルールの要点（参考）

- 手札 2 枚、場に最大 5 枚（フロップ 3・ターン 1・リバー 1）
- スモールブラインド / ビッグブラインドあり
- ベッティングが複数回あり、レイズも複数回あり得る
- 人数が多いと 1 ハンドが長くなる

## 役の強さ（参考）

ハイカード → ワンペア → ツーペア → スリーカード → ストレート → フラッシュ → フルハウス → フォーカード → ストレートフラッシュ → ロイヤルフラッシュ

文化祭の説明・判定は簡易版の表に従う。
