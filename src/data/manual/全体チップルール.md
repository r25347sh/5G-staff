# チップのルール（文化祭）

実金は使いません。すべておもちゃチップです。

## 種類と価値

| 見た目の目安 | 価値 |
| :---: | :---: |
| 小さい / 薄い色 | **5** |
| 中くらい | **25** |
| 大きい / 目立つ色 | **100** |

卓によって色が違う場合は、**その卓の開始時に「これは5・これは25・これは100」と宣言**してから始める。

## お客様への渡し方

- 受付または各卓で、最初の持ち分を渡す（運営の指示額。例: **合計 200〜500**）
- なくなったらその卓ではプレイ終了。補充の可否は運営判断
- 他の卓から持ってきたチップも、同じ価値として扱う

## 各ゲームでの使い方（統一）

| ゲーム | 基本の賭け |
| :--- | :--- |
| ルーレット | お客様がレイアウトに置く（最低 **5** 推奨） |
| ブラックジャック | 配る前にベット（最低 **10** 推奨） |
| ポーカー（簡易） | 開始時にアンティ **10**（全員同額） |
| チンチロ | 子が親に対して賭ける（最低 **10** 推奨） |

金額は運営が変更した場合は、**その指示を優先**する。

## スタッフの注意

- 清算は声に出して確認する（例: 「赤当たり、25 が戻ってさらに 25」）
- チップの貸し借り・本物の金銭との交換は禁止
- 落とした場合は一旦ゲームを止め、拾ってから再開
- 閉店・交代時はチップを回収し、数えやすい場所に戻す
