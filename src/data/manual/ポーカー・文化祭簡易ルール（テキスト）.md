# ポーカー（文化祭・簡易版）

名前: **フロップ・ショーダウン**。通常のホールデムより短く・簡単。

## この卓の約束

| 項目 | 内容 |
| :--- | :--- |
| 人数 | **2〜4 人**（5 人目は次のゲーム） |
| トランプ | 52 枚（ジョーカーなし） |
| アンティ | 開始時に全員 **同じ額**（推奨 **10**） |
| 場のカード | **フロップ 3 枚だけ**（ターン・リバーなし） |
| アクション | フロップ後に **1 回だけ** |
| 再レイズ | **禁止** |
| 1 組の目安 | **最大 3 ハンド** で交代 |

1 ハンドの目安: **2〜3 分**。

## 1 ハンドの流れ

1. 全員がアンティを出す
2. 各人に手札 **2 枚**（裏）、場に **3 枚**（表）
3. 手札 2 ＋ 場 3 の **合計 5 枚** で役を考える（約 20 秒）
4. ディーラーの左から時計回りに、次のいずれか **1 回**
5. 残った人が手札を見せ、いちばん強い役がポット全額

### アクション

| 行動 | 意味 |
| :--- | :--- |
| フォールド | 降りる。アンティは戻らない |
| コール | 追加で **アンティと同額** を出す |
| レイズ | 追加で **アンティの 2 倍**（そのハンドで **1 人まで**） |

レイズされたあと、まだ動いていない人は **フォールド** か **コール（レイズ額に合わせる）** のみ。

## 役の強さ（弱い → 強い）

| 順位 | 役 | 説明 |
| :---: | :--- | :--- |
| 1 | ハイカード | 役なし。一番高い札 |
| 2 | ワンペア | 同じ数字が 2 枚 |
| 3 | ツーペア | ペアが 2 つ |
| 4 | スリーカード | 同じ数字が 3 枚 |
| 5 | ストレート | 数字が連続 5 枚（マーク不問） |
| 6 | フラッシュ | マークが全部同じ 5 枚 |
| 7 | フルハウス | 3 枚＋ 2 枚 |
| 8 | フォーカード | 同じ数字が 4 枚 |

これより上（ストレートフラッシュなど）が出たら、その役の勝ちでよい。

### ストレート

- A は **1 にも 14 にも**使える（A-2-3-4-5 と 10-J-Q-K-A）
- K-A-2-3-4 のようなまたぎは無効

同じ役のときは高い数字（キッカー）で比較。それでも同じなら **分割**。

## 声かけ例

手札 2 枚と場の 3 枚で役を作ります。最初に参加費を出して、そのあと降りる・乗る・少し上げる、のどれか 1 回です。いちばん強い役の人が場のチップをもらえます。

## スタッフ

- 考える時間が長いときはフォールドを勧めてよい
- 役判定は上の表を見る。無理に暗記させない
- トラブル時はそのハンド無効・アンティ返却で次へ
- 実金禁止。手札ののぞき見禁止
- 通常ホールデム（ブラインド・ターン・リバー・何度もレイズ）は使わない
