# チンチロ（文化祭）

サイコロ 3 個で親と子が勝負する。文化祭では人数と倍率を抑えて回転を優先する。

## この卓の約束（簡易）

| 項目 | 内容 |
| :--- | :--- |
| 道具 | サイコロ 3 個、茶碗（器） |
| 人数 | 親 1 ＋ 子 **最大 3**（合計 4） |
| 賭け金 | 子がそれぞれ同額（推奨 **10**）。親は受けて立つ |
| 振る回数 | 1 人あたり **最大 3 回**。役が出た時点で確定 |
| 倍率 | 下表のとおり（ピンゾロは **3 倍** に統一） |
| 1 組の目安 | **2〜3 局** で親を交代、または席を空ける |

1 局の目安: **1〜2 分**。

## 1 局の流れ

1. 子が賭け金を出す
2. **親**が振る（最大 3 回）。即勝ち・即負けの役なら子は振らず清算
3. 親に「通常の目」が出たら、**子**が順に振る（最大 3 回）
4. 親の役と子の役を比べ、チップを渡す
5. 次の局へ。親の交代タイミングは「数局ごと」または「ピンゾロが出たら」など卓で統一

最初の親: 各自 1 回振って強い役の人、またはじゃんけんで決めてよい。

## 役の強さ（強い順）

| 順位 | 役 | 条件 | 倍率 |
| :---: | :--- | :--- | :---: |
| 1 | ピンゾロ | 1-1-1 | **3倍** |
| 2 | アラシ（ゾロ目） | 2〜6 の三つ揃い | **3倍** |
| 3 | シゴロ | 4-5-6 | **2倍** |
| 4 | 通常の目 | ペア 2 個＋バラバラ 1 個。バラバラの数字が「目」（6 が最強、1 が最弱） | **1倍** |
| 5 | ヒフミ | 1-2-3 | **2倍支払い（即負け）** |
| 6 | ションベン | サイコロが器の外 | **即負け** |
| 7 | 目なし | 3 回振っても役なし | 通常の目より弱い |

アラシどうしは **数字の大きい方が強い**（6-6-6 が最大）。

## 清算（親 vs 子・1 人ずつ）

- 親の方が強い → 子は親に、賭け金×倍率を支払う
- 子の方が強い → 親は子に、賭け金×倍率を支払う
- 同じ通常の目、または双方目なし → **引き分け**（移動なし）
- ヒフミ・ションベンは出した側の即負け（相手の役を待たない）

倍率が両方にかかる場合は、**勝った側の役の倍率**で支払う。

## 声かけ例

サイコロ 3 個です。親が振ってから子が振り、強い方がもらえます。器の外に出たらその場で負けです。

## スタッフ

- 子は最大 3 人。多いときは交代制
- 振り直しは「役が確定するまで」で、確定後は振らせない
- ションベンは開始前に方針を統一する（軽く外れた場合の 1 回許しなど）
- 実金禁止
